# AI Agent Rules: BrowserStack Exploratory & Automation Suite

* Every test method must contain at least one assertion. Use descriptive assertion messages that explain what the expected outcome is.

* Use timeouts for all tests so that the tests don't take too much time when there is a failure. For Playwright tests, keep a default timeout as 3000 ms.

* Do not retry fixing an issue more than once

* Add necessary comments to all methods

* Use getByText methods as the first choice of locator for buttons.
